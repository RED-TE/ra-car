RE:CAR 크루 신뢰 개선본 - 운영 반영 전 확인

이 작업은 로컬 개선과 검증까지만 수행했다. 운영 배포 승인으로 간주하지 않는다.
Flutter, 운영 서버 API, 운영 DB, 기존 동의 기록과 실제 신청·승인·정산 데이터는 수정하지 않았다.
별도 작업 트리에서 서버의 약관 버전 연결 코드를 준비했으며 운영 반영은 하지 않았다.

1. 공개 웹과 관리자 진입 경로는 서로 다른 저장소다.
   공개 웹: RED-TE/ra-car, codex/crew-trust-improvements-20261014
   관리자: RECAREA/recar_app, codex/crew-trust-improvements-20261014
   기존 PR121의 크루 진입 변경과 충돌하지 않도록 검토한다. PR121 전체를 임의 병합하지 않는다.

2. 정적 웹 개선본을 먼저 반영하고 아래 파일의 HTTP 200을 확인한 뒤 관리자 진입 변경을 반영한다.
   /crew/welcome.html
   /crew/policy.html
   /crew/trust.css?v=20261014
   /assets/crew-docs/recar-crew-quick-guide-20261014.pdf
   /crew/login.html?action=apply
   /crew/index.html
   /crew/njob/
   /crew/guide/#rewards
   새 정적 파일이 준비되기 전에 /crew를 새 소개 파일로 돌리면 404가 발생한다.

3. 기존 가입 약관 v1.3과 기존 9페이지 설명서 원본은 삭제·덮어쓰기하지 않는다.
   새 4페이지 PDF는 안내 요약이며 약관 개정이나 새로운 법적 동의를 대신하지 않는다.
   사용자는 실제 운영 게시일부터 신규 가입에만 적용하는 기준을 승인했다.
   사용자는 기존 조항을 유지하며 운영자·4개 브랜드 차량 혜택·신규 가입 적용 기준만 반영하도록 승인했다.
   v1.4-preview.pdf는 승인된 변경표 1쪽 + 수정하지 않은 v1.3 원문 16쪽의 미게시 준비본이다.
   개인정보·정산·향후 약관 변경·관할 등 다른 조항은 수정하지 않았다.
   준비본은 정식 시행 문서가 아니다. 독립적인 법률 검토를 수행했다는 의미도 아니다.
   실제 게시 시각이 확정되면 변경표만 정식 게시용으로 준비하고 17쪽 구성·동의 링크·해시를 다시 검증한다.
   서버가 기록하는 terms_version과 신청 화면의 원문을 함께 맞춘다.
   과거 v1.3 동의 기록은 그대로 보존한다. 임의의 시행일을 기재하지 않는다.

4. 크루 운영자는 사용자가 확인한 조홍철로 표기한다.
   메인 홈페이지의 다른 대표자·사업자번호·주소를 조홍철의 사업자 정보로 옮기지 않는다.
   차량 혜택은 BMW·Tesla·벤츠·제네시스 선택 가능, 유효 계약 100대, 1년 이용 지원이다.
   소유권 이전, 모든 예시 차종 보장, 계약 없이 확정 보상 또는 고정 수익으로 안내하지 않는다.

5. 관리자 기존 운영 의존성의 보안 경고는 별도 검토한다.
   npm audit --omit=dev: critical 1 / high 3 / moderate 1.
   현재 잠금 파일에는 Next.js 16.3.4, Axios 1.18.1, sharp 0.35.4 등이 있다.
   경고가 실제 서비스에서 악용 가능한지까지는 이번 작업에서 확정하지 않았다.
   임의 npm audit fix --force나 보안 게이트 우회는 수행하지 않는다.

6. 승인된 배포 후 실제 .com 주소에서 별도 검증한다.
   비로그인 /crew -> 크루 소개, 신청 -> 정보 입력 폼, 로그인 -> 승인 계정 대시보드.
   기존 세션은 승인된 대시보드로, 오래된 정상 ref는 /app/?ref=...로 연결되어야 한다.
   추천 공유문에는 수수료 관계와 유효 계약·인도 조건이 포함되어야 한다.
   사용자 또는 전용 테스트 연락처로 가입한 뒤 관리자 승인과 대시보드 노출을 확인한다.
   실제 지급·계약·고객 개인정보는 운영 검증 승인 없이 만들거나 변경하지 않는다.

검증 요약은 같은 폴더의 crew-trust-20261014.json에 기록했다.

추가 약관 버전 연결 준비 사항
- 서버 기본값은 계속 v1.3이다. v1.4는 자동 활성화하지 않는다.
- 실제 원문 게시 후 FRIENDS_TERMS_VERSION, FRIENDS_TERMS_EFFECTIVE_AT,
  FRIENDS_TERMS_DOCUMENT_SHA256를 일치시킨다. 실제 게시 시각은 시간대가 포함된 ISO 형식이어야 한다.
- 준비본 해시를 운영 활성화에 사용하지 않는다. 정식 문서는 실제 게시 시각을 기재한 별도 불변 파일이어야 한다.
- 정식 문서도 변경표 1쪽 + 원문 16쪽으로 유지하고, 링크 쪽 번호는 약관 1 / 개인정보 9 / 보상·정산 7 / 광고 안내 16이다.
- 신규 가입용 공개 원문 링크와 기존 v1.3 가입자의 이력 링크를 구분해 갱신한다. 기존 원문은 보존한다.
- API GET /api/v1/friends/terms가 신규 신청의 적용 버전과 원문 주소·해시를 내려준다.
- 새 문서가 누락되거나 해시가 다르면 신청 화면은 제출을 막고 입력 내용을 보존한다.
- 게시 전부터 열어 둔 신청서의 버전이 바뀌면 체크를 해제하고 재동의를 요청한다.
- 이전 v1.3 동의가 있는 프로필을 재신청 과정에서 v1.4로 덮어쓰지 않는다.
- DB 스키마 변경은 없으며, 새 동의 증빙은 기존 append-only 감사 로그에 추가한다.
- 웹 테스트는 API·게시 정보를 모의 처리했다. 실제 준비본의 해시와 다섯 동의 링크도 추가 검증했으나 운영 게시 검증은 아니다.
- 최신 검증: 서버 73건, 브라우저 75건, 웹 빌드 단위 테스트 20건 통과.
- 원문 16쪽은 본문·내용 스트림 비교 및 120dpi 이미지 비교에서 변경이 없었다.
- 준비본 파일·해시·승인 범위는 crew-terms-v14-preview.json에 기록했다.
