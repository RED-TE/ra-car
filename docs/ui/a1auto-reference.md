# A1auto 실측 및 RE:CAR 적용 기록

관찰일: 2026-09-08. 대상: https://a1auto.io/.
PC 1440 x 1000, 모바일 390 x 844에서 실제 브라우저의 폰트·이미지 로딩 후 확인했다.
숫자는 DOM 측정 및 화면 관찰값이며, 일부는 반올림한 근사값이다. 브라우저 스크롤바가 있는 레퍼런스의 실제 콘텐츠 폭은 뷰포트보다 약 15px 작았다.

PC·모바일 메뉴, 제조사/차량 탐색, 슬라이드 조작, FAQ, 상담 진입을 확인했다.
모바일 메뉴는 오른쪽 패널과 외부 오버레이로 열리며 Escape로 닫혔다. 상담은 스크롤 가능한 모달이었다.
레퍼런스의 상담에는 아무 정보도 입력하거나 제출하지 않았다. 실제 상담 접수 이후 동작은 확인하지 않았다.
버튼·링크의 hover/선택 상태는 강조색과 배경 전환 중심이었다. 키보드로 닫기와 포커스 이동을 확인했지만 타사 전체 접근성 감사를 수행한 것은 아니다.

## 증거 파일

이 작업의 로컬 `artifacts/a1auto-ui/reference/`에 저장했다. 타사 캡처는 프로덕션 자산 및 커밋에 포함하지 않는다.

- `desktop-first.png`, `desktop-full.png`, `desktop-catalog.png`
- `desktop-special.png`, `desktop-guides.png`, `desktop-faq.png`, `desktop-lower-8.png` (푸터)
- `mobile-first.png`, `mobile-full.png`, `mobile-catalog.png`
- `mobile-menu.png`, `mobile-consult.png`, `mobile-lower-*.png`
- `viewport-metrics.json`: 실제 DOM 치수

헤드리스 브라우저의 A1auto 접속은 두 번 타임아웃되었다. 이후 실제 인앱 브라우저에서 렌더링과 끝까지 스크롤을 확인하고 캡처했다. 따라서 시각 관찰은 완료했지만 헤드리스 레퍼런스 재캡처는 보장하지 않는다.

## RE:CAR 적용 결정: 관찰 사실과 구분

1. 1200px 본문, 86px 헤더, 750 x 424 배너, 양옆 노출, 8개 바로가기, 차량 레일, 어두운 차량 밴드, 가이드, 서비스 안내, FAQ, 밝은 푸터 순으로 구성했다. RE:CAR의 기존 상담 폼과 법인 상담 진입은 유지했다.
2. 빨강 강조색을 기존 RE:CAR `--accent` 파랑으로 치환했다. 중립 배경과 어두운 차량 밴드는 유지했다. 오류·성공은 별도 상태색이다.
3. 타사의 프로모션 이미지·인물·후기는 사용하지 않았다. 히어로는 기존 RE:CAR 홍보 이미지이며, 카탈로그 개별 차량 사진·트림의 증빙으로 사용하지 않는다. 차량 카드는 기존 실제 카탈로그 이미지다.
4. 확실한 특가·재고·기간 근거가 없어 특가 밴드를 SUV 모아보기로 바꾸고 카운트다운·재고 배지를 생략했다. 후기·평점·누적 고객 수는 만들지 않고 같은 회색 밴드에 4단계 상담 절차를 넣었다.
5. 조건은 RE:CAR 기존의 60개월, 선납 0%, 보증 0%, 연 10,000km를 그대로 표시한다. A1auto의 다른 조건 기본값을 옮기지 않았다. 옵션 변경처럼 보이는 가짜 가격 조절기는 만들지 않았다.
6. 제조사·차종·렌트/리스·검색·정렬은 실제 카탈로그 필터다. 홈에는 PC 최대 24개, 모바일 최대 3개를 노출하며 전체 목록은 기존 차량 페이지로 연결한다. 기본 제조사 선택은 국산 전체이며 A1auto의 특정 제조사 기본 선택과 다르다.
7. 자동차 카드는 실제 상담 입력으로 연결한다. A1auto 하위 상세 페이지 전체를 새로 복제하지 않고 기존 RE:CAR 차량 목록·딥링크를 유지한다.
8. 상담은 기존 `#quote` 인라인 폼이다. 타사의 모달 및 미리 체크된 동의 설정은 채택하지 않았다. 기존 필수 입력·2개 개별 동의·접수 API·추천 귀속이 우선이다.
9. 모바일 고정 메뉴는 같은 5개 구조지만 실제 RE:CAR 기능만 연결한다. 입력 필드 포커스 중 하단 메뉴를 숨겨 폼 접근을 확보하고, 외부 상담 위젯은 중복 배치하지 않았다.
10. 한국어는 기존 Pretendard를 재사용했다. 글자·가격·버튼은 실제 DOM이다. 새 UI 프레임워크나 런타임 패키지를 추가하지 않았다.
11. 모바일 차량 이미지 영역의 크기는 유지하되, 차량 뒤쪽까지 식별할 수 있도록 과도한 크롭 대신 contain으로 표시했다.

## 두 차례 비교와 수정

- 구조 검토: `artifacts/a1auto-ui/structure-pass/`. 헤더, 히어로와 바로가기 시작 위치, 본문 폭, 가로 레일/모바일 세로 목록을 비교했다. 정적 파일 허용 목록에 새 CSS·JS가 없어 발생했던 최초 무스타일 화면을 수정했다.
- 디테일 검토: `artifacts/a1auto-ui/detail-pass/`. 로고에 남은 기존 반전 필터, 웹폰트 미적용, 제조사 영문/한글 로고 매칭, 모바일 가격·필터 배치를 수정했다.
- 최종: `artifacts/a1auto-ui/implementation/`. 모바일 제조사 단일 행, 부제 대비, 가로 스크롤 영역의 키보드 접근, 푸터의 밝은 배경과 링크 대비, 웹폰트 압축을 반영했다. 브랜드·상품·문구 때문에 다르므로 픽셀 일치율을 산정하지 않았다.
